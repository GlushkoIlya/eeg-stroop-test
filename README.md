## Описание

Приложение реализует классический **тест Струпа (Stroop test)** для оценки когнитивной гибкости, избирательности внимания и устойчивости к интерференции. Тест состоит из трёх последовательных частей (T1, T2, T3), каждая со своей инструкцией. Испытуемый выбирает ответ из четырёх вариантов, нажимая на экранные кнопки. Все события (предъявление стимулов, ответы, маркеры) логируются с наносекундной точностью и могут быть синхронизированы с ЭЭГ-записью через COM-порт или в эмуляционном режиме.

## Основные возможности

### 1. Три части теста Струпа
- **T1 – Названия цветов чёрным цветом**  
  Испытуемый выбирает смысл слова (название цвета). Варианты ответа – цветные прямоугольники.
- **T2 – Цветные прямоугольники**  
  Показывается цветной прямоугольник, задача – выбрать название его цвета. Варианты ответа – обычные текстовые кнопки.
- **T3 – Конфликтные слова**  
  Слова напечатаны цветом, отличным от их смысла. Задача – назвать цвет чернил (игнорируя значение). Варианты ответа – текстовые кнопки со случайным цветом шрифта.

### 2. Интерактивный интерфейс
- Четыре кнопки ответа под стимулом, порядок и внешний вид случайны для каждого предъявления.
- Таймер текущей части, прогресс-бар, отображение стимула (текст или цветной прямоугольник).
- Отдельная вкладка **Справка** с подробной инструкцией и описанием показателей.

### 3. Анализ результатов
После завершения теста во вкладке **Анализ → Результаты теста** отображаются:
- **Среднее время реакции (мс)**
- **Медиана времени реакции**
- **Стандартное отклонение**
- **Количество ошибок и процент ошибок** для каждой части.
- **Эффект интерференции** (T3 – T1).
- **Дополнительные показатели:**
    - **ID = T3 – T2** – ригидность/гибкость контроля (чем выше, тем больше интерференция).
    - **IR = T2 / T3** – относительный показатель интерференции (чем выше, тем меньше влияние интерференции).
    - **IK = T2 / T1** – вербальность (>1 – преобладание словесной обработки, <1 – сенсорно-перцептивной).

### 4. Синхронизация с ЭЭГ
- **Реальный режим:** отправка маркеров через COM-порт на ЭЭГ-усилитель (jSerialComm).
- **Режим эмуляции:** программная генерация маркеров с настраиваемым джиттером (базовая задержка, СКО, вероятность выброса).
- Все события логируются в CSV с временными метками (наносекунды, миллисекунды стеновых часов).

### 5. Настройки эксперимента
- Количество стимулов на каждую часть (от 1 до 100).
- Задержка после ответа (пауза перед следующим стимулом).
- Выбор режима работы (эмуляция / реальный COM-порт).
- Параметры джиттера, имя COM-порта, папка для логов, идентификатор эксперимента.

## Сборка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/ваш_логин/eeg-stroop-test.git
cd eeg-stroop-test

# Сборка проекта
mvn clean package

# Запуск через Maven
mvn javafx:run

# Запуск собранного JAR-файла
java -jar target/eeg-experiment-suite-2.0.0.jar

# Создание установщика Windows (EXE)
# Требуется JDK 17+ и jpackage
mvn package
jpackage --type exe \
  --name "EEGStroopTest" \
  --input target/ \
  --main-jar eeg-experiment-suite-2.0.0.jar \
  --main-class eeg.Main \
  --win-dir-chooser --win-shortcut --win-menu

```


Все временные метки: `nano_time` – System.nanoTime(), `wall_clock_ms` – System.currentTimeMillis(), `delay_ms` – задержка отправки маркера (или 0 для других событий).

## Инструкция по проведению эксперимента

1. **Настройки** – задайте количество стимулов на часть (например, 10), выберите режим работы (эмуляция для отладки или реальный COM-порт), при необходимости настройте джиттер.
2. **Запуск** – нажмите «Запустить». Появится инструкция для первой части. Испытуемый нажимает «Продолжить» и выполняет задания, кликая на кнопки ответа.
3. После завершения всех трёх частей результаты автоматически сохраняются в папке `EEGLogs` (или указанной в настройках).
4. **Анализ** – перейдите на вкладку «Анализ» → «Результаты теста» и нажмите «Обновить статистику». Вы увидите таблицу с временами реакции, ошибками и дополнительные показатели ID, IR, IK.
5. **Экспорт** – можно экспортировать полный CSV-лог и текстовый отчёт о точности синхронизации.
